# Token Images

Place token images here with the following naming convention:
- btc.png
- eth.png
- sol.png
- usdc.png
- doge.png
- ada.png
- dot.png
- link.png
- uni.png
- aave.png
- default.png (fallback image)

All images should be:
- PNG format
- Square aspect ratio (recommended: 64x64 or 128x128)
- Transparent background preferred
